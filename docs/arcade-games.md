# 游乐场大陆 · 游戏化关卡设计

游乐场（arcade）是藏宝图上的第四块大陆，承载竞技性/游戏性强的练习形式。
与学术大陆共享：星星解锁链、错题本、AI 点评、积分榜——所有游戏在结束时
合成为标准答题记录（questions/answers/perQuestionMs），全链路零改动复用。

## 已实现玩法

### 1. 单词消消乐（kind=match，3 关）
- 玩法：英文卡片与中文卡片混洗成网格，点选两张配对消除。
- 判分：每对卡片对应一道「『en』的中文是？」合成选择题；
  首点即中记答对，错配则该题记为答错（记孩子点错的那张）。
- 数据：复用 `VOCAB` 主题词库（`vocabThemes()` 按关合并主题）。
- 关卡：热身(问候+文具 6对) → 进阶(颜色+数字 8对) → 大师(动物+食物 10对)。

### 2. 古诗词接龙（kind=poemchain，2 关）
- 玩法：给出诗题+上句，四选一接出下一句；连对有连击计数。
- 判分：每句一题，选项为全部诗句中抽取的干扰项。
- 数据：复用 `POEMS`（二上必背 4 首），候选为相邻句对。

### 3. 数字贪吃蛇（kind=snake，2 关）
- 玩法：棋盘 15×15，蛇头上方展示一道口算题，场上随机分布 4 个数字
  （1 正确 + 3 近邻干扰），操控蛇吃到正确数字。
- 判分：吃对=答对进下一题；吃错=记该题答错并立即换下一题；
  撞墙/撞自己不扣分，蛇复位重来（低幼友好，避免挫败感）。
- 操控：触屏方向盘（网格四键）+ 键盘方向键/WASD。
- 节奏：蛇速按档位 230/190/150ms 每格；答题越快食物刷新越快，
  天然形成「又快又准」的激励。

### 4. 打地鼠（kind=whack，2 关）
- 玩法：九宫格冒出头像，敲出「中文对应的单词」（词义敲词）。
- 关卡：热身(身体+家庭) → 单词(词义敲词 8 轮)。

### 5. 翻牌记忆（kind=memory，2 关）
- 玩法：记忆翻牌配对，卡片先扣着（消消乐的记忆版）。
- 关卡：热身(身体+家庭 6 对) → 挑战(动作+天气 8 对)。

### 6. 逃离切尔诺贝利（kind=escape，1 关，2026-10-03）
- 玩法：纯动作逃生——三关卡滚屏大地图（厂房/厂区/居民楼），梯子/跳跃平台跳跃，
  钥匙+齿轮+排汽阀目标链，火焰/蒸汽/坠落 HP，三档难度（计时×1/.75/.6），
  种子化随机地图 + BFS 可达性验证，触屏虚拟方向键；爆炸倒计时叙事。
- 接入：独立单文件 `demo/chernobyl-escape/index.html`（唯一源）→ prebuild 同步
  `public/escape/index.html`，`EscapeView.tsx` iframe 壳，通关 postMessage 合成
  标准答题记录。随时可玩（跳过解锁链）。

### 7. 核电站主控实践（kind=reactor，1 关，2026-10-03）
- 玩法：反应堆模拟——确定性简化物理模型（功率/温度/压力/中子密度四态纯函数
  `reactorPhysics.ts`，控制棒 96 根 12 组+冷却流量+硼浓度+AZ-5 急停），
  Canvas 2D 堆芯动画 + 熔毁特效（WebAudio 轰鸣警报）；5 任务梯度含随机扰动。
- 与 escape 组成叙事二部曲（先学操控，再面对事故）；零 LLM。
- 回归：`scripts/reactor-smoke.mjs` 5 场景断言。

## 候选玩法 backlog（调研记录）

按「开发成本 / 教学价值 / 适龄性」评估，优先级从高到低：

### 短期可做（复用现有数据，1 天内）
1. **口算接龙**（kind=mathchain）：上一题答案参与下一题（如「上一题答案
   +7 = ?」），链条式心算。纯 generateQuestions 扩展，无新 UI。
2. **拼音/音标钓钓乐**（kind=fish）：屏幕上漂着多条鱼各带一个字，
   钓起与读音匹配的鱼。复用 chars 字库。

### 中期（需要新数据或新交互，2~3 天）
3. **数学华容道/数字拼图**：滑块拼出正确算式。交互重，教学密度高。
4. **单词拼写打字机**（kind=spell）：看中文打英文单词，字母逐个敲，
   错字母即时红。适合键盘环境（iPad 配键盘/桌面）。
5. **成语/词语消消看**（kind=idiom-link）：相邻字块连成词语即消除
   （类「羊了个羊」堆叠消除变体）。
6. **口算塔防**：算对一题发射一颗子弹打怪。视觉重，需动画资源。

### 长期（内容依赖强）
7. **古诗词飞花令**：给关键字从多首诗中挑含该字的句（需扩诗库）。
8. **英语自然拼读闯关**：听音选字母组合（需 TTS/音频资源）。
9. **数学迷宫**：每道门一道题，答对开门（需关卡编辑器）。
10. **多人竞速对战**：复用 battle 上报通道，实时双人同题竞速。

### 筛选原则
- 玩法外壳可以花哨，但内核必须是「可判分的题」——每局结束都要能
  合成 Question/answers 记录，才接得上星星/错题/AI 点评/积分榜。
- 触屏优先：所有交互必须单手可达，不依赖键盘（键盘为增强）。
- 限时软约束：超时只影响完成度，不中断游戏（避免低幼挫败）。
