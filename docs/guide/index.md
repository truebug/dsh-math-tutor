# 快速上手

## 孩子篇

1. 打开首页，填昵称/年级，进入寻宝地图
2. 点「数学/语文/英语大陆」跳到最新可闯关；「🎡 游乐场」有消消乐、古诗词接龙、
   数字贪吃蛇、打地鼠、翻牌记忆
3. 左上角🌞是每日挑战（每天题目一样，全班可比拼）；点中央🌳智慧树可直达任意已解锁关
4. 答完题点「✨ AI 点评」听老师讲评；错题进错题本，可随时重练
5. 集星进化宠物、攒积分冲排行榜、解锁勋章（看板页有勋章墙）

## 家长篇（看板页）

- **云端同步**：勾选监护人同意后开启，换设备输入家庭 ID **或孩子昵称**即可恢复
- **昵称冲突**：同昵称已被绑定时，选择「是我本人恢复」或「重名新人新开」；
  建议设置 4-6 位 PIN 给孩子档案加锁
- **成长看板**：正确率趋势、错因分析、知识点热力图、每周成长报告——大数字周环比、
  7 天练习柱状图、分科对比表、亮点与重点关注、AI 老师寄语（语音可读，可打印 A4）
- 停止同步只影响本机，云端数据可联系管理员删除
