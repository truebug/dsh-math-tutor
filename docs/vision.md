# 愿景：AI agent 与孩子共同成长

> 「因材施教，各走各路」——不是千人一面的枯燥灌输，而是 agent 在陪伴中理解每一个孩子。

## 为什么选 DeepSeek Harness

DSH「一切皆插件」的 Cordis 架构天然适合长期演化：能力以插件叠加，agent 的上下文、记忆与工具可以随孩子年级增长持续升级，而不必推翻重来。我们选择的不是一次性交付的练习软件，而是一个**能和孩子一起长大的 agent 宿主**。

## 演化路径

```
阶段 A：既有范式（现在）
  固定知识点 → 确定性出题 → 判分/计时
  目标：可用、可靠、孩子愿意用

阶段 B：数据积累
  练习记录/错题本 → 结构化学习者画像（learner profile）
  易错类型、答题速度、知识点掌握度

阶段 C：个性化匹配
  agent 基于画像动态调整：难度梯度、练习重点、复习节奏
  讲解风格贴合孩子（举例偏好、鼓励方式、措辞难度）

阶段 D：共同进化
  孩子升年级 → agent 知识体系同步扩展（数学 → 语文 → 英语）
  agent 的推荐策略随反馈持续校准，越用越懂这个孩子
```

## 对应到代码

| 愿景概念 | 载体 | 演进 |
|---|---|---|
| 学习者画像 | `packages/progress-tracker` | localStorage 记录 → 结构化 profile → agent 可读写的长期记忆 |
| 难度/进度匹配 | `packages/grade-mapper` + `math-generator` | 固定知识点 → 画像驱动的参数（题量、上限、题型混合比） |
| 个性化讲解 | LLM 调用层（`apps/server`） | 通用讲解 → 基于画像的因材施教（措辞、例子、鼓励方式） |

## 边界

- 出题与判分永远是确定性代码（可靠性红线）；AI 负责「怎么教」，不负责「判对错」。
- 儿童数据最小化收集，画像默认本地存储，家长可见、可清除。
