# Phase 5 方案：简易方程（五年级）

## 题型与交互（已定）

- **题型**：`ax + b = c` 与 `ax − b = c`（a∈2~9，保证整数解 x∈1~20），
  后续扩展 `x + b = c`、`ax = c`（乘法逆运算）
- **答题交互**：复用现有数字键盘，题干显示 `3x + 5 = 20`，孩子只输入 **x 的值**。
  判分 = 把 x 代回方程验证（确定性），不是字符串比对
- **难度分级**：L1 一步方程（x + b = c、ax = c）；L2 ax ± b = c；
  L3 含括号/两边都有 x（a(x + b) = c）——L3 先占位
- **几何（暂缓）**：面积/周长需要图形渲染（SVG 矩形/三角形标注），
  作为 Phase 5b 单独设计，不在本次范围

## 地图：黄金圣殿后新增三关（数学大陆）

`方程小镇`(L1·20题) → `方程古堡`(L2·30题) → `方程天空城`(L3·40题占位)

## 需要改动的交互组件

1. `core.ts`：新 op `'eq'`，出题参数从方程结构反推（先定 x、a、b 再算 c，保证整数解）
2. `RaceView`：题干渲染支持 `3x + 5 = 20, x = ?` 格式（纯文本即可，键盘不变）
3. 错因聚类新增「移项错误」（孩子答案 = c−b 忘了除 a 之类，可按差值模式识别）

确认后即可开工。
